# Heytea Style Illustration（喜茶风插画）

## Overview

本 Skill 将用户的任意主题转化为一幅「喜茶风」插画图片：速写本手账气质、极简留白、手绘×实物拼贴混搭。核心是把主题拆解为「主角物体 + 互动小人 + 唯一彩色焦点 + 手写短标题」四个要素，再用固定视觉语言生成。

生成时**必须**使用 ImageGen 工具，并按下述流程组装提示词。

## 工作流程

1. **解析主题**：从用户输入中提取——主题是什么？主角物体用什么具象物体隐喻？画面需要一个什么短标题（4~8 个字，可从用户原话提炼）？
2. **读取风格规范**：完整阅读 `references/style-guide.md`，严格按其中的配色、构图、质感、排版规则执行。
3. **组装提示词**：按 style-guide.md 中的提示词模板填充，逐条核对检查清单。
4. **生成与交付**：调用 ImageGen 生成图片，展示给用户。若用户不满意，只微调「主角物体/短标题/彩色焦点」三要素，**不得**改动风格基底。

## 硬性规则（每次生成都必须遵守）

- 底色必须是奶油米白纸纹底（#F7F4EC ~ #FAF7F0），禁止纯白、禁止深色底。
- 主体用黑色/深灰细线钢笔速写涂鸦，线条松弛、允许不闭合。
- 全画面彩色只允许出现在一个焦点元素上（真实摄影质感的小块拼贴或小面积高饱和色块）。
- 必须有至少一个迷你小人正在与巨大物体互动。
- 文字必须是手写体中文短句，散落在留白处，可竖排；除标题外最多 1~2 处小注。
- 留白 ≥ 画面 60%，主体偏置，不居中对称。
- 禁止复制任何现有品牌 logo、现有插画的具象内容；只复用风格规律。

## 详细规范

配色色值、构图细则、字体气质、完整提示词模板与范例见 `references/style-guide.md`——每次生成前必须通读。
