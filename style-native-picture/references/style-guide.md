# 喜茶风插画 · 视觉风格规范

本规范描述一套固定的视觉语言。目标是「同一种审美，无限个主题」。只复用规律，不复用任何现有插画的具体内容。

## 1. 配色系统（固定不变）

| 角色 | 颜色 | 参考色值 | 用法 |
|---|---|---|---|
| 底色 | 奶油米白 | #F7F4EC（可浮动至 #FAF7F0 / #F2EEE3） | 整个画面背景，带细腻纸纹颗粒质感 |
| 线稿色 | 墨黑/深灰 | #2B2B2B（可浮动至 #3A3A3A） | 所有手绘线条、小人、箭头、文字 |
| 焦点色 | 高饱和实物色 | 按主题选 1 个：柠檬黄 #F5C518、葡萄紫 #6B4E93、番茄红 #D93025、抹茶绿 #7A9B57、橘子橙 #E8853D 等 | 只出现在画面唯一焦点上 |
| 辅助色 | 浅卡其/暖灰 | #E8E2D4 | 可选：用于极少量阴影或第二物体，面积不超过 10% |

**铁律**：全画面 ≈ 90% 无彩（米白底 + 黑线），≈ 10% 焦点色。焦点色只能有一处主焦点。禁止出现第二种高饱和色大面积铺开，禁止渐变底色、禁止冷白。

## 2. 插画质感（固定不变）

- **线条**：黑色细线钢笔/针管笔速写，线条松弛、随手、允许断线和不闭合，像速写本涂鸦而非精稿。
- **混搭拼贴**：焦点元素使用「真实摄影质感」（如一杯真实饮品的照片局部）拼贴进手绘画面，边缘可以不整齐，像贴在手账本上。若主题不适合实物拼贴，改用小面积高饱和手绘色块（保留纸纹透出）。
- **纸感**：整体要有纸张颗粒/纤维质感，像在素描纸上创作。

## 3. 构图规则（固定不变）

- **留白 ≥ 60%**：物体只占画面一角或一侧，大面积留白是气质来源。
- **主体偏置**：主体放在黄金分割位置（偏左下/右上等），绝不居中对称。
- **尺度反差**：1~2 个迷你小人（火柴人级别的简笔小人）与巨大物体互动——爬梯子够物体顶部、拉绳子、坐在物体边缘、推物体。小人是画面的趣味与叙事核心。
- **标注元素**：手绘箭头、虚线、小圆圈标注，从文字指向物体细节，像随笔批注。

## 4. 文字与排版（固定不变）

- **标题**：手写体中文短句，4~8 字（如「今天 负责清爽」「很多认真」「藏着点甜」），像钢笔随手写的字，不使用印刷体。
- **排布**：标题散落在留白处，可竖排、可断行错落、可沿物体边缘排布；允许 1~2 处更小的注释文字（如英文小注、日期、小标签）。
- **层级**：1 个主标题 + 少量小注，禁止多级标题堆叠、禁止边框、禁止卡片色块包裹文字。

## 5. 提示词模板（生成时套用）

```
奶油米白色纸张背景（#F7F4EC），细腻纸纹颗粒质感，像速写本内页。
画面主角：{具象物体隐喻}，以黑色细线钢笔速写涂鸦风格绘制，线条松弛随意、允许不闭合。
{1~2个迷你简笔小人}正在与这个巨大物体互动：{具体互动动作，如爬梯子够物体顶部 / 坐在边缘晃腿 / 用绳子拉拽}。
画面中唯一的彩色焦点：{焦点元素及其颜色}，呈真实摄影质感，像一小块照片拼贴在手绘画面上。
手写体中文短标题「{4~8字短句}」像钢笔随笔字迹散落在留白处，{竖排/错落断行}，配手绘箭头和虚线小标注指向物体细节。
大量留白（占画面60%以上），主体偏置于{方位}，极简杂志海报排版，无框线无装饰边框，速写手账气质，竖版构图。
```

### 填充示例

- 主题「秋天第一杯桂花拿铁」→ 主角：一杯巨大桂花拿铁；焦点色：焦糖橙 #E8853D 的真实咖啡拉花照片局部；标题「秋天 第一口暖」；小人爬梯子往杯口撒桂花。
- 主题「我做一个审美 Skill」→ 主角：一颗巨大苹果/一台老式电脑；焦点色：真实红苹果照片局部；标题「藏着 点方法」；小人坐在旁边翻开笔记本。

## 6. 生成前检查清单

- [ ] 底色是奶油米白而非纯白/深色？
- [ ] 线稿是松弛的黑色速写，而非精细插画/扁平矢量？
- [ ] 彩色只有一处焦点？其余是黑白线稿？
- [ ] 有迷你小人在和巨大物体互动？
- [ ] 标题是手写体中文短句且散落留白处？
- [ ] 留白够多、主体偏置？
- [ ] 没有复制任何现有插画的具体内容？
